# 微信登录与扫码登录

## 1. 功能目标

为移动端和跨端场景提供微信相关登录入口与扫码登录确认能力，补充传统用户名密码登录之外的接入方式。

## 2. 功能范围

- 微信小程序登录
- 微信公众号登录
- 微信公众号授权地址获取
- 扫码登录会话创建、状态轮询、手机端确认
- 微信待绑定账号查询与绑定
- JSAPI 配置服务

## 3. 菜单位置

## 9. 权限规则

- 相关入口大多为公共入口，不要求先进入后台菜单
- 扫码登录依赖移动端确认，会话状态必须从 `PENDING -> SCANNED -> CONFIRMED/CONSUMED`
- 微信公众号待绑定列表与绑定动作预计受登录用户与后台权限控制，细节待补充

## 13. 页面操作步骤
### 第一步：
从 `/mobile` 或 `/mobile-dev` 进入移动端入口，根据环境选择微信相关登录方式。
### 第二步：
如果走扫码登录，桌面端创建二维码会话，移动端进入 `/mobile/qr-confirm` 查看待确认会话。
### 第三步：
移动端确认后，桌面端轮询二维码状态，由 `PENDING/SCANNED` 进入 `CONFIRMED/CONSUMED`。
### 第四步：
如遇到公众号未绑定账号场景，可通过待绑定记录与绑定接口完成关联，具体后台操作说明待补充。

## 14. 常见问题

- 二维码会话超时会导致状态失效
- 微信环境与普通浏览器环境差异会影响登录入口可用性
- 公众号用户可能先命中“待绑定”而不是直接登录成功

## 15. 风险点

- 微信接口、授权地址和前端入口环境强相关
- 扫码登录存在时效性和多端状态同步问题
- 待绑定记录与正式绑定状态不一致时，容易造成重复绑定或无法登录

## 16. 防回归点

- 验证二维码会话创建、状态轮询、手机端确认全链路可用
- 验证二维码过期后不会被重复消费
- 验证微信小程序 / 公众号登录接口返回结构符合前端预期
- 验证待绑定记录能正确查询并完成绑定
