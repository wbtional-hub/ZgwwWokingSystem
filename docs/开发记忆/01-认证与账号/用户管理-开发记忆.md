# 用户管理

## 1. 功能目标

维护系统用户基础资料、启停状态、重置密码等账号信息，并为组织树、权限、登录链路提供用户主数据。

## 2. 功能范围

- 用户分页查询
- 用户详情查看
- 用户新增
- 用户编辑
- 用户删除
- 重置密码
- 展示组织树相关只读字段
- 当前登录用户防误触保护

不含：
- 组织关系创建与移动
- 模块授权配置

## 9. 权限规则

- 路由为 `adminOnly`
- 前端说明明确：真正安全控制以后端为准
- 当前登录用户存在防误触保护：
  - 不允许删除当前登录用户
  - 不允许重置当前登录用户密码
  - 编辑当前登录用户时禁止停用自己

## 13. 页面操作步骤
### 第一步：
进入 `/users`，通过关键字和状态筛选定位目标用户。
### 第二步：
点击列表卡片进入详情，核对账号、姓名、单位、组织树字段和状态信息。
### 第三步：
如需修改，进入编辑弹层完成保存；如需处理登录问题，可执行重置密码。
### 第四步：
保存、删除或重置密码后，回看详情或列表摘要，确认状态、更新时间和提示信息是否正确。

## 14. 常见问题

- 用户管理与组织架构职责容易混淆：组织关系应优先在组织架构页维护
- 当前登录用户相关操作受限，容易被误认为按钮异常
- 列表、详情、编辑三种状态切换较多，容易出现上下文残留问题

## 15. 风险点

- 与 `orgtree` 的边界不清时，容易误改层级字段
- 列表、详情、编辑之间状态联动复杂，容易出现旧详情残留
- 当前登录用户防误触规则一旦回退，风险较高

## 16. 防回归点

- 验证列表、详情、编辑、删除、重置密码主链路可用
- 验证当前登录用户不可删、不可重置密码、不可停用自己
- 验证关闭详情、切换筛选、翻页后不会残留旧上下文
- 验证组织树字段仍保持只读展示，不在此页错误维护
