# 单位管理与打卡点

## 1. 功能目标

维护单位基础信息、启停状态和单位主打卡点配置，为组织归属、考勤定位校验和规则配置提供单位级基础数据。

## 2. 功能范围

- 单位列表查询
- 新增单位
- 编辑单位
- 启停单位
- 删除单位
- 查询单位打卡点
- 保存或更新单位打卡点
- 地图选点与地址回填

- 路由为 `adminOnly`
- 单位管理是组织与考勤的基础配置能力
- 打卡点配置结果会影响考勤定位校验

## 13. 页面操作步骤
### 第一步：
进入 `/units`，通过列表或搜索定位目标单位。
### 第二步：
根据需要新增、编辑、启停或删除单位基础信息。
### 第三步：
打开“打卡点设置”后，查看当前已保存打卡点，并通过地图或轻量选点模式选择新位置。
### 第四步：
保存后回看名称、半径、经纬度和地址是否已正确回显，并确认未保存保护与恢复入口正常。

## 14. 常见问题

- 未配置地图 Key 时会自动回退到轻量选点模式
- 单位打卡点与考勤规则属于不同配置层，容易被混淆
- 当前仍保留旧表兼容逻辑，容易让人误以为单位只在一张表中维护

## 15. 风险点

- 单位与旧表兼容路径并存
- 打卡点保存结果会直接影响考勤定位判断
- 关闭弹层、恢复状态、选点结果等交互细节较多，容易回退
