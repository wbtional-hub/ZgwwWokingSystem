# 工作评分

## 1. 功能目标

将周报完成情况、考勤天数和纪律情况等汇总为统一评分结果，形成个人得分、等级、状态和导出报表，作为统计分析的直接上游。

## 2. 功能范围

- 查询评分列表
- 触发评分计算
- 查看评分详情
- 导出评分报表
- 上游功能：周报管理、考勤统计、考勤工作台、组织架构
- 下游功能：统计分析、管理排行、经营复盘

## 13. 页面操作步骤
### 第一步：
进入 `/scores`，先选择周次、单位范围和状态。
### 第二步：
如需刷新数据，执行评分计算。
### 第三步：
查看 Top10、单位均分和评分列表，并打开详情核对单人得分组成。
### 第四步：
如需对外留档，导出评分报表并与统计分析页结果交叉复核。

## 14. 常见问题

- 评分结果异常时，往往不是本页本身，而是上游周报或考勤口径变化
- 刚补卡或刚审批完周报后，若未重算评分，列表不会自动反映
- 状态 `RED / YELLOW / NORMAL` 与总分、等级共同决定展示效果

## 15. 风险点

- 评分是统计分析的直接上游，风险扩散面大
- 上游 `attendance_record` 与 `weekly_work` 任一异常都会影响评分
- 导出结果若与页面不一致，会直接影响管理判断

## 16. 防回归点

- 验证查询、计算、详情、导出四条主链可用
- 验证 `work_score` upsert 逻辑不会产生同周重复记录
- 验证补卡与周报审批完成后重新计算可更新结果
- 验证列表、Top10、单位均分与详情口径一致
