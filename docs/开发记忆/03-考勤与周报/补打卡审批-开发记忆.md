# 补打卡审批

## 1. 功能目标

为管理人员提供统一的补打卡审批入口，对本组织范围内待处理补卡申请执行通过或驳回，并形成可追踪审批痕迹。

## 2. 功能范围

- 查询待审批补打卡申请
- 查看补卡申请详情
- 审批通过或驳回
- 按组织树范围控制可审批记录
- 上游功能：补打卡申请、组织架构、用户管理、登录认证
- 下游功能：考勤工作台、考勤统计、工作评分、操作日志

## 3. 菜单位置

- `考勤与周报 -> 补打卡审批`
- 手机工作台中也可见 `补打卡审批`

## 13. 页面操作步骤
### 第一步：
进入 `/attendance/patch-approvals`，确认当前默认待审批状态和筛选条件。
### 第二步：
按关键字、补卡类型、日期范围筛选出需要处理的申请。
### 第三步：
打开审批弹窗，填写审批意见后选择“通过”或“驳回”。
### 第四步：
审批完成后返回列表，确认状态变化并在相关工作台复核结果。

## 14. 常见问题

- 列表为空不一定代表没有申请，可能是组织范围或筛选条件限制
- 审批后工作台未同步，通常需要进一步核查回写链路
- 不在当前审批范围的记录不会出现在本页

## 15. 风险点

- 审批范围由组织树路径决定，组织调整后可能带来漏审或越权
- 同一补卡单重复处理可能导致状态错乱
- 审批状态与考勤记录未同步时，统计和评分会出现口径差异

## 16. 防回归点

- 验证待审批分页查询可用
- 验证通过、驳回两条主链均能落库
- 验证审批意见可回看
- 验证审批后申请人页和工作台状态同步变化
