# 咨询台账

## 1. 功能目标

统一沉淀 AI 会话明细、来源场景、统计摘要和导出能力，作为运营回查和结果承接主入口。

## 2. 功能范围

- 会话列表
- 统计卡片
- 趋势图
- Skill / 用户排行
- 来源场景筛选
- 归档 / 恢复
- CSV / Excel 导出

## 3. 菜单位置

- AI模块 -> 咨询台账

## 4. 页面路径

- `/ai-ledger`

## 9. 权限规则

- 普通用户默认只看自己的会话
- 管理员可扩大查询范围
- 仍受 Skill 授权过滤影响

## 10. 当前状态

- 已能承接 AI工作台与手机端政策咨询数据
- 已支持按来源场景区分查询

## 13. 页面操作步骤
### 第一步：
进入 `/ai-ledger`，先选择来源场景、时间范围和关键词。
### 第二步：
查看统计卡片与趋势是否符合预期。
### 第三步：
在列表中核对目标会话的 Skill、来源场景和消息量。
### 第四步：
按需归档、恢复或导出明细。

## 14. 常见问题

- 手机端数据查不到，优先筛选 `MOBILE_POLICY_CONSULTANT`。
- 统计与列表不一致，优先检查筛选条件是否统一。
- 导出缺字段，优先检查导出口径是否同步带上 `source_scene`。

## 15. 风险点

- `source_scene` 新增后，列表、统计、趋势和导出必须保持同口径。
- 普通用户与管理员共用页面，权限过滤不能失效。

## 16. 防回归点

- 验证 `AI_WORKBENCH` 与 `MOBILE_POLICY_CONSULTANT` 都能查到数据
- 验证统计 / 趋势 / 列表 / 导出口径一致
- 验证归档恢复不影响来源场景筛选
