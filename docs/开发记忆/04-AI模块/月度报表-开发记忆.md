# 月度报表

## 1. 功能目标

按年度和来源场景汇总 AI 咨询经营数据，确认手机端政策咨询和 AI 工作台是否都已进入统计闭环。

## 2. 功能范围

- 年度概览
- 本年趋势
- 去年对比
- Skill / 知识库 / 用户 / 专家排行
- Excel 导出
- 来源场景筛选

## 3. 菜单位置

- AI模块 -> 月度报表

## 13. 页面操作步骤
### 第一步：
进入 `/ai-monthly-report`，选择统计年份。
### 第二步：
按用户、Skill、来源场景和关键词收口统计范围。
### 第三步：
查看概览、趋势和排行，确认手机端来源是否已进入统计。
### 第四步：
按需导出 Excel 供运营或管理侧使用。

## 14. 常见问题

- 月报里没有手机端数据，优先检查来源场景筛选。
- 趋势有数据但排行为空，优先检查专家/Skill 关联数据。
- 去年对比异常，优先检查跨年查询是否带上相同来源场景。

## 15. 风险点

- 年报、趋势、排行和导出必须保持同一来源场景口径。
- 去年对比如果丢了 `source_scene` 条件，会造成统计误差。
