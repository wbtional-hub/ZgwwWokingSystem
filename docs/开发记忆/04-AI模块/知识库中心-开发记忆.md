# 知识库中心

## 1. 功能目标

将政策、网页、快照和文档内容沉淀为可检索、可引用、可授权的知识库，为 Skills 和 AI 工作台提供知识输入底座。

## 2. 功能范围

- 知识库列表查询
- 新增 / 编辑知识库
- 启停知识库
- 设置当前工作知识库
- 删除知识库
- Word 文档导入
- 网页预览与导入
- 网页快照预览与导入
- 文档列表、详情、切片列表、知识检索

## 9. 权限规则

- 管理员拥有全部知识库能力
- 普通用户按知识库授权控制：
  - `listBases` 只能看到已授权查看的知识库
  - 文档详情、切片查询需要查看权限
  - `importDocx` 需要上传权限
  - `search` 需要分析权限
- 知识库创建人默认拥有该知识库能力

## 13. 页面操作步骤
### 第一步：
进入 `/knowledge`，先查看左侧知识库列表，确认当前使用中的知识库与目标知识库。
### 第二步：
如需新建或修改知识库，在右侧表单维护名称、适用领域、简介、状态和备注。
### 第三步：
根据需要执行文档导入、网页导入或快照导入，并回看最近一次导入结果。
### 第四步：
导入完成后，通过文档列表、切片列表和知识检索验证知识是否已经可被正常命中。

## 14. 常见问题

- 知识库是否可见并不只取决于管理员身份，还取决于知识库授权
- 删除失败不一定是异常，可能是知识库下已有文档或切片
- 当前工作知识库由参数表持久化，不再是前端临时状态

## 15. 风险点

- 权限、当前工作知识库、文档导入、切片构建四条链路高度耦合
- 网页导入涉及普通 HTTP 与浏览器渲染兜底两套路径
- 一旦知识库编码、状态或权限判断回退，会影响 Skills 与工作台

## 16. 防回归点

- 验证知识库新增、编辑、启停、设为当前使用、删除主链路可用
- 验证普通用户授权过滤生效
- 验证 Word、网页、快照三类导入链路可用
- 验证导入后文档、切片、检索结果一致
