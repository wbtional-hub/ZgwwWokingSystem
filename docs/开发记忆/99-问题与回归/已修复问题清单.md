# 已修复问题清单

说明：
- 本文件只记录“已明确修复且适合长期复用”的问题。
- 临时排查但没有结论的碎片，不放入本文件。
- 若历史来源不够充分，会明确写 `待补充`，不凭空补造。

## 1. 登录 403 与代理链路不一致

- 问题标题：登录 403 与代理链路不一致
- 所属功能：登录认证
- 现象：浏览器登录时出现 403，容易误判为后端鉴权或 CSRF 问题
- 根因：前端 `baseURL=/api`、Vite 代理和后端真实登录路径未完全对齐，同时叠加浏览器缓存干扰
- 修复方式：统一前端 `/api` 代理口径，校正登录和 `/api/auth/me` 链路
- 影响范围：登录页、当前用户上下文、所有依赖登录态的页面
- 回归验证点：验证 `POST /api/auth/login`、`GET /api/auth/me`、强制改密跳转
- 来源记录：`ai-memory/DEV_MEMORY.md`、`ai_docs/07_PROJECT_PROGRESS.md`

## 2. 用户页可误操作当前登录用户

- 问题标题：用户页缺少当前登录用户防误触保护
- 所属功能：用户管理
- 现象：当前登录用户可能被误删、误停用、误重置密码
- 根因：早期页面未对“当前登录用户”特殊对象做显式限制
- 修复方式：增加当前登录用户标识，并限制危险操作
- 影响范围：用户管理、登录连续性、账号安全
- 回归验证点：验证当前登录用户不可删除、不可停用、不可重置本人密码
- 来源记录：`ai_docs/07_PROJECT_PROGRESS.md`、`ai-memory/TASKS.md`

## 3. 组织树节点移动导致循环结构

- 问题标题：组织树可被移动到自身或下级
- 所属功能：组织架构
- 现象：非法移动会造成树结构异常
- 根因：`tree_path` 更新链路中，目标节点合法性未被完整拦截
- 修复方式：前端过滤非法目标，后端继续保留防循环校验
- 影响范围：组织树、数据范围、审批链、用户归属
- 回归验证点：验证移动到自身或下级时前后端都会拒绝
- 来源记录：`ai-memory/DECISIONS.md`、`ai-memory/DEV_MEMORY.md`

## 4. 节点单位调整后子树未同步

- 问题标题：组织架构设置单位后子树归属不一致
- 所属功能：组织架构 / 单位管理与打卡点
- 现象：只调整当前节点单位，会造成整棵子树 `unit_id` 不一致
- 根因：单位归属不是单点字段，会影响新增、移动和查询规则
- 修复方式：编辑节点单位时，同步更新当前节点及全部下级 `unit_id`
- 影响范围：组织架构、单位管理、考勤归属、用户新建继承规则
- 回归验证点：修改单位后核对整棵子树单位归属一致
- 来源记录：`ai_center/progress.md`

## 5. 周报审批快照字段缺失导致状态与按钮异常

## 15. 考勤定位超出范围误判

- 问题标题：地图上看着在范围内，提交后仍判超出范围
- 所属功能：考勤工作台
- 现象：浏览器定位点在地图范围内，但后端返回 `OUT_OF_RANGE`
- 根因：浏览器原始定位坐标与高德地图配置点存在 `WGS84 / GCJ-02` 混用，同时早期未上送 `accuracy`
- 修复方式：前端同时计算原始坐标和 GCJ-02 转换后坐标，自动选择更接近打卡点的一组提交；后端补齐 `accuracyMeters` 接收与日志
- 影响范围：打卡成功率、异常判定、补卡链路
- 回归验证点：验证坐标系转换、精度日志、距离提示和实际判定一致
- 来源记录：`ai_center/progress.md`

## 16. 室内弱定位被误判为超出范围

- 问题标题：室内打卡定位失真时被误报超出范围
- 所属功能：考勤工作台
- 现象：室内弱信号场景被直接判为 `OUT_OF_RANGE`
- 根因：未把“无效定位”“弱定位”“真实超范围”三类情况拆开
- 修复方式：新增 `LOCATION_INVALID / LOCATION_WEAK` 分支，并加入基于 `accuracy` 的弱定位容错
- 影响范围：打卡体验、异常率、补卡数量
- 回归验证点：粗定位不再误报超范围，弱信号提示清晰，真实超范围仍继续拦截
- 来源记录：`ai_center/progress.md`
