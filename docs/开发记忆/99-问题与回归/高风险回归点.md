# 高风险回归点

说明：
- 本文件按功能沉淀高风险项。
- 每个功能至少记录：风险点、典型回退表现、联动影响、最小验证步骤。

## 登录认证

- 风险点：登录返回结构、`/api/auth/me` 字段、前端登录态读取口径不一致
- 典型回退表现：登录成功后首页异常、菜单异常、个人中心信息缺失
- 联动影响：所有依赖当前用户信息的页面
- 最小验证步骤：验证登录、获取当前用户、强制改密跳转和退出登录

## 微信登录与扫码登录

- 风险点：二维码状态机、待绑定、微信环境判断
- 典型回退表现：二维码生成但无法确认，确认后桌面端不登录
- 联动影响：移动端入口、扫码登录、微信绑定
- 最小验证步骤：按 `PENDING -> SCANNED -> CONFIRMED -> CONSUMED` 走完整链路并覆盖超时

## 用户管理

- 风险点：当前登录用户防误触、详情/编辑/列表状态切换、组织边界
- 典型回退表现：能删自己、能停用自己、关闭详情后残留旧数据
- 联动影响：账号安全、登录状态、组织归属理解
- 最小验证步骤：重点验证当前登录用户限制、详情关闭清理、保存后详情回看

## 个人中心与强制改密

- 风险点：`forcePasswordChange` 状态、密码弹层关闭逻辑、AI 摘要口径
- 典型回退表现：已改密仍反复被要求改密、页面状态与实际授权不一致
- 联动影响：登录认证、AI 缺权排查、专家摘要展示
- 最小验证步骤：带强制改密标记进入页面，修改密码成功后核对状态清理和摘要加载

## 组织架构

- 风险点：`tree_path`、节点移动、防循环、单位同步、模块授权入口
- 典型回退表现：子树层级错乱、可移动到非法目标、菜单权限错乱
- 联动影响：数据权限、审批链、用户归属、菜单显示
- 最小验证步骤：验证新增下级、移动节点、查看上级链、打开模块授权弹窗

## 单位管理与打卡点

- 风险点：单位兼容旧表、打卡点未保存保护、地图模式回退
- 典型回退表现：保存后打卡点不回显、关闭弹层丢数据、无地图 Key 时无法配置
- 联动影响：考勤定位、规则判定、补卡数量
- 最小验证步骤：覆盖正式地图模式、轻量模式、已保存恢复、未保存关闭确认

## 菜单模块授权

- 风险点：菜单过滤、路由守卫、模块定义与数据库记录不一致
- 典型回退表现：用户看不到应有入口、能手输未授权 URL、保存后菜单不刷新
- 联动影响：后台所有模块入口、AI 功能入口、管理员配置链路
- 最小验证步骤：给测试用户授权一个模块并重新登录，核对菜单和未授权路由拦截

## AI权限配置

- 风险点：AI / 知识库 / 技能三层权限半开通、用户切换误保存、结果区错位
- 典型回退表现：看得到 AI 菜单却不能用，结果区有记录但实际不可用
- 联动影响：个人中心、知识库、Skills、AI 工作台、专家台账
- 最小验证步骤：给同一用户依次保存三层权限，再到个人中心与 AI 工作台验收

## 参数管理

- 风险点：参数编码漂移、假成功、误删高频参数
- 典型回退表现：页面提示成功但列表无数据；依赖参数的功能突然失效
- 联动影响：地图配置、当前工作知识库、默认值与运行口径
- 最小验证步骤：新增测试参数，验证保存、编辑、启停、删除与错误提示都真实反映后端结果

## 考勤工作台

- 风险点：查询联动、异常监控、补卡链路、规则与打卡点口径
- 典型回退表现：筛选残留、异常人数不准、打卡后列表与结果区不同步
- 联动影响：考勤统计、工作评分、补卡数量
- 最小验证步骤：验证工作台查询、打卡、异常榜单、当前范围提示和列表回刷

## 补打卡申请

- 风险点：重复申请、申请与考勤记录口径不一致、移动端与 Web 入口不同步
- 典型回退表现：同一天同一时段重复提交、申请列表状态异常、详情缺失
- 联动影响：补打卡审批、考勤工作台、考勤统计
- 最小验证步骤：提交四种补卡类型各一条，查看我的申请列表和详情

## 补打卡审批

- 风险点：组织树范围审批、重复审批、审批后回写不同步
- 典型回退表现：审批列表缺记录、同一单重复处理、审批后工作台状态未变化
- 联动影响：补打卡申请、考勤统计、工作评分、操作日志
- 最小验证步骤：走一遍“查询待审批 -> 通过 / 驳回 -> 申请页回看 -> 工作台回看”

## 考勤规则

- 风险点：单位规则切换、宽限分钟口径、规则变更后的历史数据解释
- 典型回退表现：规则保存后工作台无变化、切换单位后读取错规则
- 联动影响：考勤工作台、补打卡、考勤统计
- 最小验证步骤：切换单位保存规则，再回到工作台和统计页复核

## 考勤统计

- 风险点：统计口径、补卡刷新时点、非工作日提示
- 典型回退表现：团队人数不对、异常名单不准、概览卡和明细不一致
- 联动影响：工作评分、统计分析、管理复盘
- 最小验证步骤：选同一天核对工作台、补卡审批、统计页三层结果

## 周报管理

- 风险点：审批快照、真实审批人、退回重提、分区焦点回落
- 典型回退表现：按钮显示错误、非当前审批人也能处理、退回后无法重提
- 联动影响：审批链、列表状态、工作评分与统计
- 最小验证步骤：至少走一遍“提交 -> 一级审批 -> 退回 -> 重提 -> 再审批”

## 工作评分

- 风险点：重算时机、评分公式、导出口径
- 典型回退表现：补卡或周报审批完成后评分未更新；导出与页面不一致
- 联动影响：统计分析、管理排行、经营判断
- 最小验证步骤：先补卡或审批周报，再触发评分计算，核对列表、详情与导出

## 统计分析

- 风险点：与考勤统计概念混淆、趋势口径、周次筛选
- 典型回退表现：排行和趋势与评分列表不一致、切换周次后卡片不变
- 联动影响：管理看板、红黄榜、经营复盘
- 最小验证步骤：切换两个周次，核对概览、排行、红黄榜、趋势同步变化

## 知识库中心

- 风险点：权限过滤、当前工作知识库、导入链路、切片一致性
- 典型回退表现：普通用户看到不该看的知识库、切换当前知识库失败、导入后搜不到
- 联动影响：Skills、AI 工作台、AI 引用结果
- 最小验证步骤：验证权限过滤、设为当前使用、导入后文档/切片/检索一致

## Skills中心

- 风险点：技能版本、发布状态、知识库绑定、验证结果
- 典型回退表现：技能列表存在但工作台不可用、发布后版本错乱
- 联动影响：AI 工作台、专家台账、月度报表
- 最小验证步骤：验证保存、发布、绑定知识库、执行验证和详情查询

## AI工作台

- 风险点：会话创建、消息记录、引用片段、权限前置
- 典型回退表现：能进工作台但无法建会话、回答无引用、台账与月报失真
- 联动影响：咨询台账、月度报表、AI结果回流、手机端政策咨询
- 最小验证步骤：验证新建会话、发送问题、查看引用和消息列表

## AI接入区

- 风险点：Base URL、Token、默认模型、连通测试、启停
- 典型回退表现：接入保存后测试失败、测试成功但工作台不可用
- 联动影响：AI 权限、Skills、AI 工作台、咨询台账
- 最小验证步骤：新建测试接入，保存并执行连通测试，再验证启停切换

## 咨询台账

- 风险点：筛选口径、统计汇总、会话状态、导出一致性
- 典型回退表现：统计与列表不一致、归档后状态不变、导出与页面口径不一致
- 联动影响：AI 工作台、月度报表、运营复盘
- 最小验证步骤：按技能和日期筛选一批会话，核对统计、趋势、列表、归档和导出

## 月度报表

- 风险点：年度口径、同比环比、专家指标、导出
- 典型回退表现：切换年份后数据不变、专家排行为空或异常、导出与页面不一致
- 联动影响：咨询台账、专家台账、管理层经营判断
- 最小验证步骤：切换两个年份，核对概览、趋势、排行与导出

## 专家台账

- 风险点：技能发布版本绑定、专家等级、维护边界
- 典型回退表现：未发布技能也能绑专家、普通用户可修改台账、月报专家指标错乱
- 联动影响：个人中心专家摘要、月度报表、AI 工作台技能归属理解
- 最小验证步骤：绑定一个已发布技能的专家身份，验证保存、回显和权限边界

## 手机端政策咨询

- 风险点：移动端权限、技能可用性、微信环境、后台统计断链
- 典型回退表现：手机端能进入但不能提问；能提问但后台无台账
- 联动影响：AI 工作台、AI结果回流、咨询台账、月度报表
- 最小验证步骤：手机端登录后发起一轮咨询，再到后台核对台账和月报

## AI结果回流

- 风险点：没有独立入口、回流逻辑分散、月报依赖长链
- 典型回退表现：有会话有回答，但台账或月报没有数据
- 联动影响：AI 工作台、手机端政策咨询、咨询台账、月度报表、日志中台
- 最小验证步骤：验证 `create session -> chat -> ledger -> monthly report` 整链路

## 日志中台

- 风险点：traceId、详情字段完整性、AI 分析文本复制、查询噪声
- 典型回退表现：列表有日志但详情为空、traceId 丢失、复制 AI 分析文本失败
- 联动影响：异常排障、AI 接入排查、工作台问题定位
- 最小验证步骤：按模块查出一条日志，打开详情并核对 traceId、请求信息和原始 JSON

## 操作日志

- 风险点：查询口径、审计字段、组织树路径过滤
- 典型回退表现：空结果无上下文、关键操作没有日志、组织范围越界
- 联动影响：用户管理、参数管理、周报管理、权限审计
- 最小验证步骤：按模块、操作人、时间范围查询，核对当前查询工作面和结果

## 启动与环境配置

- 风险点：端口占用、数据源、前端代理、Windows/WSL/服务器差异
- 典型回退表现：本地能启动但功能不可用，或本地和服务器行为不同
- 联动影响：登录、AI、考勤、扫码登录等全链路
- 最小验证步骤：核对数据库、端口、代理、环境变量，再跑登录、考勤、AI 三条最小链路

## 数据库变更总览

- 风险点：基线与增量 SQL 漏执行、参数初始化不完整
- 典型回退表现：页面可打开但接口执行报表或字段不存在、约束不匹配
- 联动影响：扫码登录、AI 月报、补打卡、评分、周报审批等近期新增能力
- 最小验证步骤：上线或联调前核对对应专题 SQL 是否执行，并核对关键表结构
